# Source documents (attribution notice)

The files in this folder are copies of published Indian government documents, kept exactly as obtained so every figure in the dataset can be checked against its source. They are listed with publisher, URL and retrieval date in `../../SOURCES.md`.

- They are reproduced unchanged, with the source named, for verification and research. We have not altered their content. Where a file arrived wrapped in a small HTML shell, the document inside is unchanged.

The MIT licence in the repo root covers our code only, not these documents.
- We are not affiliated with, and are not endorsed by, any of these bodies.
- Reuse terms for each source are not all confirmed; see `../../docs/licences.md`.
- If a publisher asks us to remove a document, we will remove it and keep only the extracted figures with their citations.
