# Action Brief: Haryana

_Data only from the Kachra Satya dataset. The CPCB and MoHUA figures are for different years; no same-year pair exists yet. Anything not in the data is marked 'not reported'._

| Generated | 9,662 tpd | 4,965 tpd |

**Gap: +24.4 percentage points** (MoHUA minus CPCB).

## 2. Likely causes (hypotheses from the data)

- **Different denominators.** Generated waste is 9,662 tpd in CPCB 2023-24 and 4,965 tpd in MoHUA 2025-26 (-49%). A percentage built on a different base will differ even if treatment were identical. Hypothesis: the state revised its generation estimate.
- **A collection gap.** Only 75% of generated waste is reported collected (7,249 tpd of 9,662 tpd), so waste cannot reach treatment. Hypothesis: door-to-door coverage gaps.

## 3. Flags raised for this state

- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): generated: CPCB 2023-24=9662.21; MoHUA 2025-26=4965; change=-48.6%. CPCB and MoHUA generated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.
- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): treated: CPCB 2023-24=4859.31; MoHUA 2025-26=3706; change=-23.7%. CPCB and MoHUA treated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.

## 4. Draft SBM-U 2.0 ask

On the CPCB figures for 2023-24, about **4,803 tpd** of 9,662 tpd generated is not reported as treated. We request:

1. A joint CPCB-MoHUA-state reconciliation of generated and treated tonnage for the same financial year, so the two published figures can be explained.
2. Central assistance under SBM-U 2.0 (solid waste component) for processing capacity, sized to the reconciled untreated quantity.
3. Support for weighbridge-based data reporting by urban local bodies so future returns pass basic checks.
