# Action Brief: Telangana

_Data only from the Kachra Satya dataset. The CPCB and MoHUA figures are for different years; no same-year pair exists yet. Anything not in the data is marked 'not reported'._

## 1. The gap

| | CPCB 2023-24 | MoHUA 2025-26 |
|---|---|---|
| Generated | 11,714 tpd | 11,577 tpd |
| Collected | 11,714 tpd | not reported by MoHUA |
| Treated / processed | 9,440 tpd | 11,237 tpd |
| % of generated treated | 80.6% | 97.1% |
| Source | ls_au50_2025-12-01.pdf, p.4 | mohua_81pct_answer.pdf, p.3 |

**Gap: +16.5 percentage points** (MoHUA minus CPCB).

## 2. Likely causes (hypotheses from the data)

- **Treatment reported much higher in the newer source.** Treated/processed rose from 9,440 tpd to 11,237 tpd. Hypothesis: real capacity added between years, or a looser definition (MoHUA 'processed' is stored as treated here and may not mean the same as CPCB 'treated').

## 3. Flags raised for this state

- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): treated: CPCB 2023-24=9440; MoHUA 2025-26=11237; change=+19.0%. CPCB and MoHUA treated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.

## 4. Draft SBM-U 2.0 ask

On the CPCB figures for 2023-24, about **2,274 tpd** of 11,714 tpd generated is not reported as treated. We request:

1. A joint CPCB-MoHUA-state reconciliation of generated and treated tonnage for the same financial year, so the two published figures can be explained.
2. Central assistance under SBM-U 2.0 (solid waste component) for processing capacity, sized to the reconciled untreated quantity.
3. Support for weighbridge-based data reporting by urban local bodies so future returns pass basic checks.

_Amount: not stated. The dataset has no state-wise allocation or utilisation figures for this state; add them from the Lok Sabha Q682 annexure before submitting._
