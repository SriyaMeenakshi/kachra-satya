# Action Brief: Maharashtra

_Data only from the Kachra Satya dataset. The CPCB and MoHUA figures are for different years; no same-year pair exists yet. Anything not in the data is marked 'not reported'._

## 1. The gap

| | CPCB 2023-24 | MoHUA 2025-26 |
|---|---|---|
| Generated | 24,299 tpd | 24,222 tpd |
| Collected | 23,975 tpd | not reported by MoHUA |
| Treated / processed | 19,877 tpd | 22,695 tpd |
| % of generated treated | 81.8% | 93.7% |
| Source | ls_au50_2025-12-01.pdf, p.3 | mohua_81pct_answer.pdf, p.3 |

**Gap: +11.9 percentage points** (MoHUA minus CPCB).

## 2. Likely causes (hypotheses from the data)

- **Treatment reported much higher in the newer source.** Treated/processed rose from 19,877 tpd to 22,695 tpd. Hypothesis: real capacity added between years, or a looser definition (MoHUA 'processed' is stored as treated here and may not mean the same as CPCB 'treated').

## 3. Flags raised for this state

- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): treated: CPCB 2023-24=19877.1; MoHUA 2025-26=22695; change=+14.2%. CPCB and MoHUA treated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.

## 4. Draft SBM-U 2.0 ask

On the CPCB figures for 2023-24, about **4,422 tpd** of 24,299 tpd generated is not reported as treated. We request:

1. A joint CPCB-MoHUA-state reconciliation of generated and treated tonnage for the same financial year, so the two published figures can be explained.
2. Central assistance under SBM-U 2.0 (solid waste component) for processing capacity, sized to the reconciled untreated quantity.
3. Support for weighbridge-based data reporting by urban local bodies so future returns pass basic checks.
