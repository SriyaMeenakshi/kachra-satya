# Action Brief: West Bengal

_Data only from the Kachra Satya dataset. The CPCB and MoHUA figures are for different years; no same-year pair exists yet. Anything not in the data is marked 'not reported'._

## 1. The gap

| | CPCB 2023-24 | MoHUA 2025-26 |
|---|---|---|
| Generated | 14,072 tpd | 7,435 tpd |
| Collected | 13,117 tpd | not reported by MoHUA |

| Source | ls_au50_2025-12-01.pdf, p.4 | mohua_81pct_answer.pdf, p.3 |

**Gap: -12.9 percentage points** (MoHUA minus CPCB).

## 2. Likely causes (hypotheses from the data)

- **Different denominators.** Generated waste is 14,072 tpd in CPCB 2023-24 and 7,435 tpd in MoHUA 2025-26 (-47%). A percentage built on a different base will differ even if treatment were identical. Hypothesis: the state revised its generation estimate.

## 3. Flags raised for this state

- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): generated: CPCB 2023-24=14072; MoHUA 2025-26=7435; change=-47.2%. CPCB and MoHUA generated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.
- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): treated: CPCB 2023-24=3300; MoHUA 2025-26=786; change=-76.2%. CPCB and MoHUA treated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.

## 4. Draft SBM-U 2.0 ask

On the CPCB figures for 2023-24, about **10,772 tpd** of 14,072 tpd generated is not reported as treated. We request:

1. A joint CPCB-MoHUA-state reconciliation of generated and treated tonnage for the same financial year, so the two published figures can be explained.
2. Central assistance under SBM-U 2.0 (solid waste component) for processing capacity, sized to the reconciled untreated quantity.
3. Support for weighbridge-based data reporting by urban local bodies so future returns pass basic checks.

_Amount: not stated. The dataset has no state-wise allocation or utilisation figures for this state; add them from the Lok Sabha Q682 annexure before submitting._
