# Action Brief: Rajasthan

_Data only from the Kachra Satya dataset. The CPCB and MoHUA figures are for different years; no same-year pair exists yet. Anything not in the data is marked 'not reported'._

## 1. The gap

| | CPCB 2023-24 | MoHUA 2025-26 |
|---|---|---|
| Generated | 7,909 tpd | 8,085 tpd |
| Collected | 7,747 tpd | not reported by MoHUA |
| Treated / processed | 1,748 tpd | 4,759 tpd |
| % of generated treated | 22.1% | 58.9% |
| Source | ls_au50_2025-12-01.pdf, p.3 | mohua_81pct_answer.pdf, p.3 |

**Gap: +36.8 percentage points** (MoHUA minus CPCB).

## 2. Likely causes (hypotheses from the data)

- **Treatment reported much higher in the newer source.** Treated/processed rose from 1,748 tpd to 4,759 tpd. Hypothesis: real capacity added between years, or a looser definition (MoHUA 'processed' is stored as treated here and may not mean the same as CPCB 'treated').

## 3. Flags raised for this state

- `3_sources_differ_gt_10pct` (2023-24 vs 2025-26): treated: CPCB 2023-24=1747.72; MoHUA 2025-26=4759; change=+172.3%. CPCB and MoHUA treated figures differ by more than 10%. These are different years (no same-year pair exists yet), so part of the gap may be real change.

## 4. Draft SBM-U 2.0 ask

On the CPCB figures for 2023-24, about **6,162 tpd** of 7,909 tpd generated is not reported as treated. We request:

1. A joint CPCB-MoHUA-state reconciliation of generated and treated tonnage for the same financial year, so the two published figures can be explained.
2. Central assistance under SBM-U 2.0 (solid waste component) for processing capacity, sized to the reconciled untreated quantity.
3. Support for weighbridge-based data reporting by urban local bodies so future returns pass basic checks.
