# Trust pages (Pod 1)

One dependency-free page: **Check a claim**, **Receipts**, **Audit first** (priority list, recurrence, volatility), **Definitions** (crosswalk and MoHUA statements over time).

## Run it
From the repo root:

```bash
python -m http.server 8777
```

Open http://127.0.0.1:8777/web/trust/index.html . The page loads `web/trust/data.js` (all data inline) and the page images from `receipts/pages/` through `RECEIPT_BASE` at the top of the script in `index.html` (`../../receipts/`). Change `RECEIPT_BASE` if the folder is deployed somewhere else.

## Rebuild the data
```bash
python scripts/validate.py
python scripts/volatility.py
python scripts/recurrence_and_priority.py
python scripts/make_receipts.py
python scripts/export_web_data.py
```

## Files
- `index.html`: the page (light and dark theme, works at phone width).
- `claim.js`: the Claim Checker in the browser, a port of `scripts/claim_checker.py`. `tests/test_web_parity.py` checks both give the same verdicts and records.
- `data.js`: generated by `scripts/export_web_data.py`; do not edit by hand.

## For Likitha's shell
Include the same three script tags and call `KSClaim.checkClaim(window.KS, {metric, value, state, year})`. Receipt keys are `State|year|metric|source_doc`; see `receipts/index.json`.

## Wording rules
Say "the sources disagree" and "figures that cannot both be true", never "wrong" or "fraud". Blank means "not reported".
