# Permission requests (drafts, not sent)

Four letters, one per publisher. Nothing has been sent. Send each from a team member's own email, copy the others, and keep every reply in `docs/permissions_log.md` (create it when the first reply arrives).

Before sending: look up the correct contact on each body's official website (the Lok Sabha copyright policy names its Editorial Branch). Do not use an address from an unofficial site. Replace the bracketed parts. If a body replies with conditions, follow them or remove the material.

What we ask for in each letter is limited to what the repo and the data release actually hold:
- the extracted figures with the document and page named (data release and repo), and
- unchanged copies of the documents and single-page images in the public repo (`data/raw/`, `receipts/pages/`) so a reader can check a figure against its source.

The Zenodo release contains the figures only, no documents or images (`docs/licences.md`).
