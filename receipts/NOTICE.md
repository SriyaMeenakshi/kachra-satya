# Receipt page images (attribution notice)

The images in `pages/` are renderings of single pages of published Indian government documents, produced so a reader can see the page a figure came from. Each image name gives the source file (for example `cpcb_2022-23_p7.png` is page 7 of `data/raw/cpcb_2022-23.pdf`). Publisher, URL and retrieval date for every document are in `../SOURCES.md`.

- The pages are reproduced accurately and unchanged. The red box that the web page draws is an overlay and is never part of the image.
- Copyright and other rights in each page remain with its publisher. The MIT licence in the repo root covers our code only.
- We are not affiliated with, and are not endorsed by, the publishing bodies.
- Reuse terms for each source are not all confirmed; see `../docs/licences.md`. On a publisher's request we will remove its page images and keep only the extracted figures with citations.
